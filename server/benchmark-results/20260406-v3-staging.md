## Notes

- V3 typecheck is faster than V2 for all fixtures (no version sync overhead).
- V3 compile times include network latency + multipart parsing. SmallComponent compile is slower than V2 build — likely due to multipart overhead on small payloads.
- Error cases (TypeError, MultiError) are very fast (6-19ms) since the compiler bails early.
- First request after deploy is slower due to dep cache miss (bun install + S3 preseed). All benchmark runs hit the warm cache.
- Auth overhead (signature verification) is negligible (<1ms per request).

## How to reproduce

```bash
cd server
go build ./cmd/tsgo-bench
./tsgo-bench --url https://flick-staging-tsgo.fly.dev --key <private-key> --runs 10
```
